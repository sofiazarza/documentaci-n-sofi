# Github

Github es una plataforma que sirve para crear un [repositorio](github.md#como-hago-el-repositorio) para luego poder usar [Gitbook](gitbook.md) y alzar tu propio sitio web para documentaciones.

## ¿Cómo crear mi cuenta?

Primero necesitamos crear una cuenta de GitHub, para eso es necesario un correo electrónico y una contraseña

<figure><img src="../.gitbook/assets/Captura de pantalla 2026-10-05 131806.png" alt=""><figcaption><p>Inicio de la plataforma GitHub.</p></figcaption></figure>

Ese inicio verás cuando logres el objetivo...

Para iniciar este proceso debes entrar al sitio web de GitHub para registrarte con tu correo electrónico.

{% embed url="https://github.com" %}

<figure><img src="../.gitbook/assets/inicio web github.png" alt=""><figcaption><p>Lugar para escribir el correo y "luego dar enter" o sea el boton verde.</p></figcaption></figure>

Luego de ingresar el correo aparecerá un cuadro para rellenar información

<figure><img src="../.gitbook/assets/crear cuenta github.png" alt=""><figcaption><p>En el cuadro verde crearás tu contraseña y en el rojo tu usuario</p></figcaption></figure>

Cuando ingreses toda la información necesaria le damos al botón verde nuevamente y te mandarán un código de 8 números al correo que inscribiste. Y listo, tienes tu cuenta de GitHub!

## ¿Como hago el repositorio?

Ahora lo difícil, mentira, es sencillo... Crearemos un "repositorio". What is that??? Es como una carpeta en la que tendrás varias cositas.

<figure><img src="../.gitbook/assets/new repository.png" alt=""><figcaption></figcaption></figure>

Haremos click en el + y luego en "New repository". Al dar click tendremos nuevamente un cuadro para rellenar y luego crearemos automáticamente nuestro nuevo repositorio.

<figure><img src="../.gitbook/assets/generar el repositorio.png" alt=""><figcaption><p>En el cuadro rojo agregamos el nombre del repositorio y dejamos que sea público como lo muestra la flecha amarilla. Por último, ponemos on a la opción de añadir un README.</p></figcaption></figure>

Y así estaremos listos para tener nuestro repositorio. Dejaré el mío aquí abajo si quieres verlo&#x20;
